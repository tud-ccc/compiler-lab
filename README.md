# Compilerbau Lab 2026


## Installation

- Install [Pixi](https://pixi.prefix.dev/): 
```
curl -fsSL https://pixi.sh/install.sh | sh
```

## Tasks

Each task has a directory in [`tasks/`](tasks/) with a README (what to
implement, where, and how to test it) and a testbed that runs your passes on a
model, e.g. `pixi run task1`.
